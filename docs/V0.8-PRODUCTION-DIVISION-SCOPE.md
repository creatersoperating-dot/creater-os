# CreatorOS v0.8 Scope

## Milestone

Production Division Completion

## Objective

Extend the released v0.7 video-production foundation into a production-capable workflow without redesigning the existing execution engine.

## In Scope

### Visual Production

- Add a real visual asset provider interface
- Preserve the current mock provider
- Generate or retrieve exactly one visual asset per scene
- Validate visual asset ownership, format, and readiness

### Audio and Rendering

- Use the approved narration audio
- Combine narration with the visual timeline
- Produce a browser-playable final MP4
- Preserve deterministic mock rendering for tests

### Provider Architecture

- Provider selection through configuration
- Server-only credentials
- Explicit provider capability contracts
- Clear provider errors and unsupported-mode errors

### Execution Controls

- Timeouts
- Retry limits
- Cost limits
- Duration limits
- Cancellation and failure handling
- Existing lease, heartbeat, recovery, and fencing protections

### Validation and Security

- Final duration validation
- Media format validation
- Storage-path validation
- Private storage
- Signed playback and download access
- Lifecycle writes through trusted server operations only

### User Experience

- Display generation progress
- Display actionable failure messages
- Display the attached final video
- Support secure playback and download
- Prevent duplicate generation requests

### Quality Requirements

- ESLint passes
- TypeScript passes
- Production build passes
- Provider and lifecycle tests pass
- Hosted generation workflow passes
- Hosted attachment workflow remains operational

## Out of Scope

The following will not be built in v0.8:

- Competitor Brain
- Outlier Brain
- Comment Brain
- Gap Brain
- Angle Brain
- Prompt Brain
- YouTube publishing
- YouTube analytics
- Autonomous channel management
- Multi-channel budget allocation
- Production-engine redesign

## Completion Definition

v0.8 is complete when CreatorOS can take an existing script, scene plan, scene visuals, and narration audio and reliably produce, validate, store, play, and download a final MP4 through the existing production lifecycle.
